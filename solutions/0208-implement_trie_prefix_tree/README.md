## Problem

A trie (pronounced as 'try') or prefix tree is a tree data structure used to efficiently store and retrieve keys in a dataset of strings. Implement the Trie class with insert(word), search(word) that returns true if word is in the trie, and startsWith(prefix) that returns true if there is any word in the trie that starts with the given prefix.
