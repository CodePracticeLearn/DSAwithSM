# 91. Decode Ways

`Medium` · `Dynamic Programming`

🔗 **[Problem on LeetCode](https://leetcode.com/problems/decode-ways/)**

## Problem

A message containing letters from A-Z can be encoded into numbers using 'A' -> '1', 'B' -> '2', ..., 'Z' -> '26'. Given a string s containing only digits, return the number of ways to decode it. If there are no valid ways to decode the message, return 0.
